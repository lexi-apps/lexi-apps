# Lexi Apps

Focused software for Windows, made by a solo developer.

**Website:** [lexi-apps.github.io](https://lexi-apps.github.io/)

| App | What it does | Price |
|---|---|---|
| **[Lexi Ren'Py Translator](https://github.com/lexi-apps/lexi-renpy-translator)** | Translates Ren'Py visual novels into other languages. | Basic is free, no account. Plus and Pro add AI translation. |
| **[Lexi Download Manager](https://github.com/lexi-apps/lexi-download-manager)** | A download manager for Windows. | Free, no ads, no account. |
